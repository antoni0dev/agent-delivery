# Architecture contract

Linear owns requested scope, GitHub owns code and check results, SQLite owns local execution claims, and hashed artifacts carry verification evidence. The composition root loads workspace configuration and credential references. Network calls never execute inside a database transaction.

Every initiative has one owner, an immutable selected runtime profile and a current accepted plan. Claims and resource reservations use database constraints and immediate transactions. Worktrees have one writer. Live integrations remain inactive until destination conformance and authority are verified.

External writes persist operation intent before dispatch. A missing response is an uncertain outcome, reconciled by a stable remote marker before retry. Evidence is bound to the plan, knowledge, configuration, head, base, environment and producer invocation. The latest attempt for each required check governs readiness, including pending and failed attempts.

The first release is a local macOS CLI with three native runtime adapters, Linear and GitHub ports, a source-indexed knowledge library, and launchd integration. Production and mainnet actions are excluded. Sources, sessions and project configuration never ship in portable exports.
