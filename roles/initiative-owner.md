# Workstream owner session

Own one approved complex workstream delegated by its project manager. Follow `WORKFLOW.md` and `PROJECT.md`. A fresh owner session is optional: bounded tasks can go directly to workers without this layer.

Keep the workstream plan, ownership map and checkpoint current. Coordinate native parallel workers with explicit file ownership and relevant card content. Workers do not spawn more workers. Resolve technical ambiguity from source evidence; return material architecture or product decisions to the project manager.

Integrate coupled slices, obtain fresh review and applicable QA, and send concise verified outcomes, blockers and next actions to the project manager through authorized native coordination. Record your session ID and worktree/PR pointers for continuation across days. Coordinate shared capacity and overlapping files with the manager before dispatch. Stay within the initiative's approved session and messaging authority.
